# Speakio 🗣️

Speakio, konuşarak dil öğrenme fikri üzerine geliştirilen mobil-first dil öğrenme uygulaması MVP'sidir.

## Mevcut özellikler

- Ana sayfa ve günlük hedef
- A1 ders haritası
- Ders tamamlama ve XP
- AI Speak konuşma ekranı
- Tarayıcı Speech Recognition desteği
- Tarayıcı metin seslendirme desteği
- Kelime hafızası
- Dinleme alıştırması
- Başarılar
- Profil ve haftalık ilerleme
- Ayarlar
- LocalStorage ile ilerleme kaydı
- Responsive mobil tasarım

## Çalıştırma

Bu ilk MVP tek sayfalı HTML uygulamasıdır. `index.html` dosyasını bir web sunucusunda açmak yeterlidir.

Sonraki aşamalarda Supabase, gerçek AI öğretmen, kullanıcı hesapları, ders/veri motoru, telaffuz değerlendirmesi ve PWA/Android paketleme eklenecektir.
